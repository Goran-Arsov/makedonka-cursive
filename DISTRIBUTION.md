# Distribution kit — Makedonka Cursive

Ready-to-paste material for posting the font on free-font sites, a blog or a download page.
Everything here follows from the licence: the font is a **CC BY-SA 3.0 derivative**, so every posting must
show the attribution below and must not claim a different licence.

## Files to upload
The release zip from GitHub (`MakedonkaCursive-v0.9.N.zip`, attached to each release at
https://github.com/Goran-Arsov/makedonka-cursive/releases). It holds one `MakedonkaCursive/` folder with
both weights in OTF, TTF, WOFF2 and WOFF, `makedonka-cursive.css`, `demo.html`, `specimen.png`, `README.md`
and `LICENSE`. Sites that want a single installable file: upload the two **OTF** files (TTF for sites that
require TrueType).

## Short description (EN)
Makedonka Cursive is a Macedonian cursive display face in two weights, Regular and Bold. It covers all 31
Macedonian letters in their correct Macedonian/Serbian-style cursive forms (overbarred г/п/т, g-shaped д),
a full Latin alphabet with the South-Slavic diacritics š č ž ć đ, figures, punctuation, currency and symbols,
and OpenType features (fractions, superscripts, tabular and slashed figures, kerning for connected joins and
all-caps). An ornate copperplate hand: use it large — headings, logos, titles, invitations.

## Short description (MK)
Македонка Курзив е македонски ракописен фонт за наслови, во две тежини — обичен и задебелен. Ги содржи сите
31 македонски букви во правилните македонски ракописни форми, целата латиница со š č ž ć đ, бројки,
интерпункција и симболи, и OpenType функции (дропки, експоненти, порамнување на верзалите). Украсен
копперплејт ракопис — за крупни наслови, лого, покани.
