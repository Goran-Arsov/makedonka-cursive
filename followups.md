# Follow-ups — Makedonka Cursive build

Start-of-session brief + what's left. Deep design notes and **every tuning knob** are in
`macedonian-cursive-font-handoff.md` (same folder). The whole font is generated by
`build/scripts/build_font.py` from `build/paths.json` (traced path data) — edit the script's knobs,
never the glyphs by hand. Kerning (`kern_util.py`) and the OpenType features (`features.py`) are added
automatically at the end of each build.

## How to work on this (read first — a new session has none of the earlier setup)
- **Build environment** — recreate the Python venv:
  `python3 -m venv .venv && .venv/bin/pip install -r build/requirements.txt`
  (fonttools, skia-pathops, pillow, numpy, brotli, psautohint, ttfautohint-py; `fontbakery` + `uharfbuzz`
  are QA-only). Run every build script with that python.
- **Iterate loop** — change a knob in `build_font.py` (handoff lists them), build into a **scratch** dir
  (`python build/scripts/build_font.py build/paths.json /tmp/try`), then **verify before shipping**: there is
  no live preview, so render words to a PNG with PIL `ImageFont.truetype(otf, size)`, or shape with HarfBuzz
  (`uharfbuzz`) to preview GPOS kerning + GSUB features (PIL applies neither). Compare old vs new.
  **Slant/width is unreliable to measure on round/ornate glyphs** — judge those by eye.
- **Ship a version** — once it looks right, rebuild the whole suite into the project dir:
  1. `build_font.py build/paths.json .`  → Regular `.otf`/`.woff2`/`.woff` + `specimen.png` (auto kern + GSUB).
     `specimen.png` now shows **both** the Cyrillic AND the full **Latin** alphabet (caps + MAKEDONIJA + lowercase +
     diacritics) — generated every build, so it stays in sync with each version (specimen canvas is 4200px tall).
  2. `make_bold.py MakedonkaCursive-Regular.otf . 16`  → Bold (faux-bold dilation D=16; auto kern + GSUB)
  3. `otf2ttf.py <in>.otf <out>.ttf` for each weight  → the two `.ttf` (auto speck-drop + ttfautohint)
  4. **bump the version** everywhere: `0.92N` in `build_font.py` (**4 strings**: CFF version, uniqueFontIdentifier,
     name version, head.fontRevision) + `make_bold.py` (`VER` + fontRevision), the `**Version 0.9.N**` line +
     jsDelivr tag in `README.md`, and `?v=NN` in `demo.html` + `makedonka-cursive.css`
  5. zip the 14 entries into `MakedonkaCursive-v0.9.N.zip` (flat top-level `MakedonkaCursive/` folder:
     both weights × otf/ttf/woff2/woff + css + demo + specimen + README + LICENSE; the zip is gitignored —
     it goes on the GitHub **release**, not in the tree)
  6. install for LibreOffice/desktop: copy both OTFs to `~/.local/share/fonts/` then `fc-cache -f`
     (LibreOffice must be fully restarted to pick up a replaced file)
  7. commit, `git push origin main`, `gh release create v0.9.N <zip> …`, update this file + the handoff
  - gh here is 2.45.0: the public flip (already done) is `gh repo edit <repo> --visibility public` (no
    `--accept-visibility-change-consequences` flag yet).
- **Private preview pages (owner-only, not in this repo):** a browser specimen (both `.woff2` embedded as
  base64 `@font-face`, so the kern renders natively) and a non-technical install/use guide exist as private
  shareable pages; the owner holds the links. (See Open work #11 — consider committing a specimen source.)

- **Coverage — 262 glyphs:** all 31 Macedonian Cyrillic letters (upper+lower) + grave-accented **ѐ/ѝ** and the
  uppercase case pair **Ѐ/Ѝ**; full **Latin** A–Z/a–z (drawn + de-skewed copies of Cyrillic sources) **plus
  South-Slavic diacritics** `š č ž ć đ` / `Š Č Ž Ć Đ`; digits 0–9; punctuation (incl. „ " « » “ ” ‘ ’ ‚ ‹ › / … · • ° %
  ¡ ¿ and the ASCII `` ` ``); **math + symbols** `+ − = × ÷ < > ± & № @ $ € © ® ™ § ¶ ‰ ′ ″ # * _ | ~ \ ^ [ ] { }`;
  precomposed `½ ¼ ¾`, superscript `¹ ² ³ ⁰–⁹`, subscript `₀–₉`; raised `.case` dashes; NBSP; U+2010/2011/2015
  aliased to the dashes. **Not** covered: other-Cyrillic, Latin-1 accented letters (scope), U+00AD (deliberately —
  FontBakery flags it).
- **Weights:** Regular + Bold — the Bold is a **contrast-preserving faux-bold** (`make_bold.py`, anisotropic
  dilation in un-slanted space, D=16, so weight lands on the thick stems while hairlines/overbars stay thin).
- **Typographic colour (v0.9.26):** the disk-brush digits/symbols/drawn-Latin were much heavier than the traced
  Cyrillic (digits ~2.4×, symbols ~1.8×, drawn-Latin ~1.3×). A per-category weight `_WT` scales every disk-brush
  radius (incl. `_rect`/`_oval`/`_ring` bars/dots/rings); `DIGIT_WT=0.45`, `LAT_WT=0.70`, symbol tiers 0.55/0.80,
  `LAT_LIGHTEN` for heavy caps. Every category now ~0.85–1.15× the Cyrillic on **both weights**; Cyrillic unchanged
  (never uses the brush). Residuals (bypass the brush): brackets `[ ]` (~2×) + lowercase `p` — minor, see Open #12.
- **Kerning:** GPOS `kern` on both weights, algorithmic (`kern_util.py`, params at its top), registered under
  DFLT+latn+cyrl. Bidirectional connection kerning + an **even body-BAND cap→cap kern** (**`CAP_BAND_GAP=290`**
  since v0.9.28): each cap's body edge = the left/right-most ink in the **cap-body band** (`CAP_BAND_LO=100..
  CAP_BAND_HI=590`u above baseline, rendered glyph), ignoring the flourishes that loop above cap-height/below
  baseline — equalised both directions so the **perceived** whitespace is uniform (body-band spread ~**1px**/word,
  both weights; was ~96px). Supersedes the v0.9.27 full-height ink-mass measure, which the flourishes skewed so
  Ѕ/Ј/С/Е read with extra space in front. Only cap-before-cap, so Title-case/lowercase unchanged. v0.9.35 added
  three positive-only **floor kerns** (`_floor_pairs`: push apart until a y-band's nearest ink approach ≥ gap):
  digit pairs (`DIG_GAP=24`), S/Š before ascender letters (`ASC_*`), ascenders before the raised quotes (`QUO_*`);
  the cap sets now include Ѐ Ѝ / Š Č Ž Ć Đ and the Latin lowercase set š ž č ć đ. Regular/Bold **2821 / 2733** pairs.
- **OpenType features (GSUB):** `tnum` tabular figures · `zero` slashed zero · `sups`/`subs` · `numr`/`dnom` ·
  `frac` fractions (multi-digit, 2–3) · `case` (raised dashes) · `calt` (a dash after a figure or a capital takes the
  raised `.case` form). Built from the digit outlines by `features.py`; HarfBuzz-verified. Both
  weights also carry a **STAT** table (Weight axis) + a **`meta`** table (dlng/slng = Latn, Cyrl). GSUB + the kern
  GPOS are compiled in ONE `add_kern(otf, extra_fea)` call — `addOpenTypeFeaturesFromString` rebuilds BOTH tables
  from its FEA, so two separate calls wipe each other (keep them in one call).
- **Hinting:** CFF alignment zones + `psautohint` (OTF) + `ttfautohint` (TTF, with the integer-ppem head flag).
- **Outlines:** UPM=700; vertical metrics harmonised (typo=hhea=win, USE_TYPO_METRICS, OS/2 v4). The TTFs drop
  degenerate zero-area **speck contours** in `otf2ttf.py` (partial overlap-WARN reduction; full fix = Open #7).
- **QA:** FontBakery **0 FAIL / 0 ERROR** per-format family (universal + Adobe, OTF + TTF). Remaining are
  intentional WARNs only: UPM=700 (deliberate render size — the OTFs' only WARN since v0.9.35), and on the TTFs
  `overlapping_path_segments` (intrinsic to the brush; Open #7), post v3 (valid for CFF), contour-count (custom design).
