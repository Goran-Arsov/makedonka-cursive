# Follow-ups — Makedonka Cursive build

Start-of-session brief + what's left. Deep design notes and **every tuning knob** are in
`macedonian-cursive-font-handoff.md` (same folder). The whole font is generated by
`build/scripts/build_font.py` from `build/paths.json` (traced path data) — edit the script's knobs,
never the glyphs by hand. Kerning (`kern_util.py`) and the OpenType features (`features.py`) are added
automatically at the end of each build; `outline_util.py` holds the shared sliver purge.

## How to work on this (read first — a new session has none of the earlier setup)
- **Build environment** — recreate the Python venv:
  `python3 -m venv .venv && .venv/bin/pip install -r build/requirements.txt`
  (fonttools, skia-pathops, pillow, numpy, brotli, psautohint, ttfautohint-py; `fontbakery` + `uharfbuzz`
  are QA-only). Run every build script with that python.
- **Iterate loop** — change a knob in `build_font.py` (handoff lists them), build into a **scratch** dir
  (`python build/scripts/build_font.py build/paths.json /tmp/try`), then **verify before shipping**: render words
  to a PNG with PIL (`ImageFont.truetype(otf, size, layout_engine=ImageFont.Layout.RAQM)` applies GPOS kern and
  default GSUB; the basic layout engine applies neither), or shape with HarfBuzz (`uharfbuzz`). Compare old vs new.
  **Comparison sheets get 10% white margin on every edge, sized from the real ink** (owner's rule, 2026-11-02 —
  a sheet once clipped the very underbar under discussion). **Slant:** the only trustworthy measure on cursive is
  the projection-profile italic angle (un-shear until the column histogram is sharpest; calibrated on the drawn
  figures, ±1° on stem-bearing groups) — row-centroid and stem-segment estimates under-read it badly; stemless
  letters (s ѕ S С о) can't be measured at all, judge them by eye against guide lines (see Open #9).
- **Ship a version** — once it looks right, rebuild the whole suite into the project dir:
  1. `build_font.py build/paths.json .`  → Regular `.otf`/`.woff2`/`.woff` + `specimen.png` (auto kern + GSUB).
     `specimen.png` shows **both** the Cyrillic AND the full **Latin** alphabet (caps + MAKEDONIJA + lowercase +
     diacritics + the standing phrases) — generated every build, so it stays in sync with each version (canvas
     4600px tall, cropped to content).
  2. `make_bold.py MakedonkaCursive-Regular.otf . 16`  → Bold (true dilation D=16; auto kern + GSUB)
  3. `otf2ttf.py <in>.otf <out>.ttf` for each weight  → the two `.ttf` (guarded outline closing + speck-drop +
     coincident-point cleanup + ttfautohint; the overlapping-segments WARN is gone since v0.9.36)
  3b. `specimen_html.py .`  → `specimen.html` (self-contained browser specimen, both woff2 embedded; ~260 KB)
  4. **bump the version** everywhere: `0.9NN` in `build_font.py` (**4 strings**: CFF version, uniqueFontIdentifier,
     name version, head.fontRevision) + `make_bold.py` (`VER` + fontRevision), the `**Version 0.9.N**` line +
     jsDelivr tag in `README.md`, and `?v=NN` in `demo.html` + `makedonka-cursive.css`
  5. zip the 15 entries into `MakedonkaCursive-v0.9.N.zip` (flat top-level `MakedonkaCursive/` folder:
     both weights × otf/ttf/woff2/woff + css + demo + specimen.png + specimen.html + README + LICENSE; the zip
     is gitignored — it goes on the GitHub **release**, not in the tree)
  6. install for LibreOffice/desktop: copy both OTFs to `~/.local/share/fonts/` then `fc-cache -f`
     (LibreOffice must be fully restarted to pick up a replaced file)
  7. commit, `git push origin main`, `gh release create v0.9.N <zip> …`, update this file + the handoff
  8. propagate to amici (section A below)
  - gh here is 2.45.0: the public flip (already done) is `gh repo edit <repo> --visibility public` (no
    `--accept-visibility-change-consequences` flag yet).
- **Private preview pages (owner-only, not in this repo):** a non-technical install/use guide exists as a private
  shareable page; the owner holds the link. The browser specimen is now generated in-repo (`specimen.html`, step 3b),
  so the old private specimen page can be retired or replaced by it.

  by a per-case shear in `letter_path` (`CYR_TARGET_DEG`, `cyr_shear`); everything drawn (Latin, figures,
  punctuation, operators) is sheared to **10°** (`T_DEG`); the Latin copies of Cyrillic sources de-skew relative
  to the shear they already carry (`_dsk`) so they land on 10°. Per-glyph overrides: `CYR_SLANT_DEG` (С 15.35°,

  did (fixed v0.9.41, now anchored to the feet); nothing else is placed that way.

  uppercase case pair **Ѐ/Ѝ**; full **Latin** A–Z/a–z (drawn, or de-skewed copies of Cyrillic sources — since

  South-Slavic diacritics** `š č ž ć đ` / `Š Č Ž Ć Đ`; digits 0–9 (hybrid 450u default + a cap-height `.case` set);
  punctuation (incl. „ " « » “ ” ‘ ’ ‚ ‹ › / … · • ° % ¡ ¿ and the ASCII `` ` ``); **math + symbols**
  `+ − = × ÷ < > ± & № @ $ € © ® ™ § ¶ ‰ ′ ″ # * _ | ~ \ ^ [ ] { }`; precomposed `½ ¼ ¾`, superscript
  `¹ ² ³ ⁰–⁹`, subscript `₀–₉`; dashes and operators in three heights (`.fig`/`.case` alternates); `.lc`

- **Weights:** Regular + Bold — the Bold is a **contrast-preserving faux-bold** (`make_bold.py`: un-slant, stretch
  y by D/DY, fill ∪ round `pathops` stroke of width 2·D, re-slant — a true D×DY-ellipse dilation; D=16, DY=7).
- **Typographic colour (v0.9.26):** the disk-brush digits/symbols/drawn-Latin were much heavier than the traced
  Cyrillic (digits ~2.4×, symbols ~1.8×, drawn-Latin ~1.3×). A per-category weight `_WT` scales every disk-brush
  radius (incl. `_rect`/`_oval`/`_ring` bars/dots/rings); `DIGIT_WT=0.45`, `LAT_WT=0.70`, symbol tiers 0.55/0.80,
  `LAT_LIGHTEN` for heavy caps. Every category ~0.85–1.15× the Cyrillic on **both weights**; Cyrillic unchanged
  (never uses the brush). Since v0.9.35 every ribbon stamps an overlap-guaranteed disk trail (`_disks`,
  `DISK_OVERLAP=1.1`), so thin hairlines stay one stroke at any weight. v0.9.36 matched the drawn Latin's
  **contrast** to the copies (`LW_DMAX` 1.45, `LW_DMIN` 0.95, `LW_EXP` 2.0): drawn hairline/thick 6/46u vs the
  traced 9/58u, mean width 1.09× the traced (was 5/40u, 0.95×).
- **Kerning:** GPOS `kern` on both weights, algorithmic (`kern_util.py`, params at its top), registered under
  DFLT+latn+cyrl. Bidirectional connection kerning + an **even body-BAND cap→cap kern** (**`CAP_BAND_GAP=290`**
  since v0.9.28): each cap's body edge = the left/right-most ink in the **cap-body band** (`CAP_BAND_LO=100..
  CAP_BAND_HI=590`u above baseline, rendered glyph), ignoring the flourishes that loop above cap-height/below
  baseline — equalised both directions so the **perceived** whitespace is uniform (body-band spread ~**1px**/word,
  both weights; was ~96px). Supersedes the v0.9.27 full-height ink-mass measure, which the flourishes skewed so
  Ѕ/Ј/С/Е read with extra space in front. Only cap-before-cap, so Title-case/lowercase unchanged. v0.9.35 added
  positive-only **floor kerns** (`_floor_pairs`: push apart until a y-band's nearest ink approach ≥ gap): digit
  pairs (`DIG_*`), S/Š/F/T before ascender letters (`ASC_*`), ascenders before the raised quotes (`QUO_*`), Ф/Ѕ
  before ascender/overbar letters (`CFL_*`); the cap sets include Ѐ Ѝ / Š Č Ž Ć Đ and the Latin lowercase set
  š ž č ć đ. Later passes: the **negative-only tuck** (v0.9.37, `_tuck_pairs`: an x-height letter after an
  apostrophe is pulled under it, 215u along the slant, cap 110), a bigger capital→apostrophe floor (v0.9.38,
  `CAP_QUO_GAP` 80), and since the de-slant (v0.9.39) a descender-band floor before j/ј (`DESC_*`), the Ф/Ѕ/Р
  flourish floor widened (cap 240, + ѐ ѝ) and d + V W U in the S/F/T ascender floor. One value per pair (floor
  wins over tuck). Regular/Bold **3069 / 3170** pairs. Overlap scan (HarfBuzz-kerned ink masks): 0 pairs in every
  category; the 16 384-triple letter+apostrophe+letter scan: 0 overlaps.
- **OpenType features (GSUB):** `tnum` tabular figures · `zero` slashed zero · `sups`/`subs` · `numr`/`dnom` ·
  `frac` fractions (denominators first, up to four figures) · `case` (cap-height figures + raised dashes/operators)
  · `calt`, on by default: cap-height figures inside all-caps runs; dashes/operators at the lowercase height
  between words, `.fig` beside hybrid figures, `.case` beside capitals; and the apostrophe `.lc` rules (after a
  short letter, leading before one, the 'n' idiom, before punctuation — all one height now). Built from the
  digit outlines by `features.py`; HarfBuzz-verified in both weights after every build. Both
  weights also carry a **STAT** table (Weight axis) + a **`meta`** table (dlng/slng = Latn, Cyrl). GSUB + the kern
  GPOS are compiled in ONE `add_kern(otf, extra_fea)` call — `addOpenTypeFeaturesFromString` rebuilds BOTH tables
  from its FEA, so two separate calls wipe each other (keep them in one call).
- **Hinting:** CFF alignment zones + `psautohint` (OTF) + `ttfautohint` (TTF, with the integer-ppem head flag).
- **Outlines:** UPM=700; vertical metrics harmonised (typo=hhea=win, USE_TYPO_METRICS, OS/2 v4). `otf2ttf.py`
  closes every outline (guarded, r=0.8u), drops degenerate speck contours and coincident points before/after the
  cu2qu conversion — the TTFs pass `overlapping_path_segments` since v0.9.36 and are ~8% smaller.
- **QA:** FontBakery **0 FAIL / 0 ERROR** per-format family (universal + Adobe, OTF + TTF). Remaining are
  intentional WARNs only: UPM=700 (deliberate render size — the OTFs' only WARN), and on the TTFs post v3 (valid
  for CFF-derived) and contour-count (custom design).
