# Follow-ups — Makedonka Cursive build

Start-of-session brief + what's left. Deep design notes and **every tuning knob** are in
`macedonian-cursive-font-handoff.md` (same folder). The whole font is generated by
`build/scripts/build_font.py` from `build/paths.json` (traced path data) — edit the script's knobs,
never the glyphs by hand.

## How to work on this (read first — a new session has none of the earlier setup)
- **Build environment** — recreate the Python venv (the earlier one lived in a temp dir and is gone):
  `python3 -m venv .venv && .venv/bin/pip install -r build/requirements.txt`
  (the build needs fonttools, skia-pathops, pillow, numpy, brotli). Run every build script with that python.
- **Iterate loop** — change a knob in `build_font.py` (handoff lists them), build into a **scratch** dir
  (`python build/scripts/build_font.py build/paths.json /tmp/try`), then **verify before shipping**:
  there is no live preview, so render words to a PNG with PIL `ImageFont.truetype(otf, size)` and measure
  with fontTools (`BoundsPen` for glyph bounds / vertical placement, `hmtx` for advance & sidebearings).
  Compare old vs new. **Slant/width is unreliable to measure on round & ornate glyphs** — judge those by eye.
- **Ship a version** — once it looks right, rebuild the whole suite into the project dir:
  1. `build_font.py build/paths.json .`  → Regular `.otf`/`.woff2`/`.woff` + `specimen.png`
  2. `make_bold.py MakedonkaCursive-Regular.otf . 14`  → Bold (faux-bold dilation of Regular)
  3. `otf2ttf.py <in>.otf <out>.ttf` for each weight  → the two `.ttf`
  4. **bump the version** everywhere: `0.9.N` in `build_font.py` (3 strings) + `make_bold.py` (`VER`),
     the `**Version 0.9.N.**` line in `README.md`, and `?v=NN` in `demo.html` + `makedonka-cursive.css`
  5. zip the 14 files into `MakedonkaCursive-v0.9.N.zip` (flat top-level `MakedonkaCursive/` folder:
     both weights × otf/ttf/woff2/woff + css + demo + specimen + README + LICENSE)
  6. install for LibreOffice/desktop: copy both OTFs to `~/.local/share/fonts/` then `fc-cache -f`
     (LibreOffice must be fully restarted to pick up a replaced file)
  7. update this file's changelog + the handoff
- **Live specimen** (optional "see it" page): `claude.ai/artifact/BdGyojA5uWSarU4Y8wiK9b` — an HTML specimen
  with both `.woff2` embedded as base64 `@font-face`. Its source is **not in the repo** (was in the temp
  scratch dir). To update: read the published artifact, swap in the new base64 woff2, republish to the same URL.

## Current state (v0.9.12, 2026-10-31)
- **Coverage — 144 glyphs:** all 31 Macedonian Cyrillic letters (upper+lower); a full **Latin**
  alphabet A–Z/a–z (drawn letters + de-skewed copies of Cyrillic sources — `LATIN_HOMO` is empty, so
  no Latin letter shares a Cyrillic glyph); digits 0–9 (equal height); punctuation incl. Latin "up"
  quotes `“ ” ‘ ’` and Macedonian `„ "`.
- **Weights:** Regular + Bold (Bold is a faux-bold dilation via `make_bold.py`).
- **Spacing-only:** no `GSUB`/`GPOS`/`kern` — "connection" is band-based spacing, no contextual joining.
- **Size:** `UPM=700`, so it renders at a normal-font size for a given point size (caps ~1.2× DejaVu,
  x-height ~0.67×). Line height is tall (flourishes) — set fixed line spacing in the app if needed.
- **Shipped to:** project dir (Reg+Bold × otf/ttf/woff2/woff + specimen + README + LICENSE),
  `MakedonkaCursive-v0.9.12.zip`, `~/.local/share/fonts/` (both OTFs, fc-cache), demo/css `?v=23`,
  and the live specimen artifact (above).
- **amici: NOT updated this session (the user's step).** amici still ships the OLD v0.9 files and does
  not display the font anyway (`--font-script` switched to Nunito in an uncommitted refactor;
  `font-makedonka` defined but used in no view). The visible CC BY-SA credit IS present in amici's public
  footer. Don't re-enable the font on the site without asking — removal looks intentional. *To display it

## Open / optional work (pull on demand; none blocking)
1. **Contrast match for drawn Latin** — the reused *copies* carry the Cyrillic high thin/thick contrast
   while the *drawn* letters are more even. Thin the drawn hairlines (`LW_DMIN`) to match, if wanted.
2. **Short caps `C` / `E` (and drawn `G`/`L`)** — `C.lat`/`E.lat` sit a touch short (their Cyrillic source has a
   bottom swash that defeats a `BASEFRAC` baseline lift — it overshoots); drawn `G`/`L` are short by their own
   design. Would need those specific caps redrawn (not a global knob). Minor. (Round cap `О` was equalized in v0.9.11.)
3. **True contextual joining (v2)** — real entry/exit connectors + `GSUB`/`calt`. Big, uncertain on
   traced standalone forms; spacing-based connection already reads whole. Likely needs Glyphs/FontForge.
4. **Pair kerning (`GPOS`)** — rhythm is good; a few specific pairs could be hand-kerned. Polish.
5. **Even consecutive capitals (`RIGHT_CAP`)** — would trim right cap-flourishes for all-caps, but
   reduces the lowercase tuck-under the user approved. Only matters for all-caps (not this font's use).
6. **Other-Cyrillic coverage** — Russian/Serbian/Bulgarian/Ukrainian-specific letters (Ё Й Щ Ъ Ы Э Ю Я …):
   new designed glyphs. (Latin is DONE.)
7. **Sharper digit edges** — the disk-brush gives a soft pen edge; a non-self-intersecting stroker would
   be crisper. Cosmetic; the solid-fill requirement is met.
8. **Public release / distribution** — offer the font free. CC BY-SA 3.0 drives the channels (it can't be
   relicensed): own VPS/blog download page (primary) + a GitHub repo & jsDelivr CDN (best ShareAlike fit);
   free-font aggregators (DaFont / FontSpace / 1001 Free Fonts / Font Squirrel) for reach. **Google Fonts
   is out** (requires OFL/Apache). Every posting needs a visible MacedonianBoy + CC BY-SA 3.0 credit. Ship
   the current `MakedonkaCursive-v0.9.12.zip`. Do once the letterforms are signed off.
